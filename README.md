# PIXORA multi-page starter
Background: `#FFF8E1`. Logo file: `assets/pixora-logo.png`.

## Pages included
Home, Search, Stock, Explore, Images, Vectors, PSD Files, Templates, Festival Designs, Marathi Creatives, Banners & Posters, Backgrounds, Projects, Library, Plans, Become a Creator, Account, Admin Panel, Design Preview and Contact.

Each navigation item opens a separate HTML page. This is a frontend prototype: sample cards are placeholders, and authentication, creator uploads, admin permissions, database, secure downloads, subscriptions and payments are not active yet.

## GitHub upload
1. Download and extract `PIXORA-multipage-files.zip`.
2. Open the `pixora-multipage` folder.
3. Upload every `.html` file plus `styles.css`, `script.js`, `README.md`, and the `assets` folder to the root of your GitHub repository.
4. Settings → Pages → Deploy from a branch → `main` → `/(root)` → Save.

Never put admin passwords or secret API keys in public frontend files.
